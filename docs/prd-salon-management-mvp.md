# PRD — kept out of this repository

The product requirements document for this project is **not published here**.

It is a pre-sales document: it names the prospect, records discovery questions
including budget and decision timeline, and sets out what happens commercially
if the deal does not close. None of that belongs in a public repository, least
of all one the prospect can find.

The code, the design specs under `docs/superpowers/specs/`, and the demo
runbook all reference it by section number — `PRD §5.5`, `§7`, and so on. Those
references still resolve against the private copy.

**Where it lives:** with the repository owner, outside version control.
